# Stock Assistant - Ассистент по акциям РФ

Проект для получения информации об акциях с Московской биржи (MOEX).

## Функции

- Получение текущей цены акции по тикеру (SBER, GAZP, LKOH и др.)
- Отображение изменения цены в процентах
- Сохранение истории запросов в базу данных
- Веб-интерфейс на Streamlit

## Эндпоинты API

| Эндпоинт | Метод | Описание |
|----------|-------|----------|
| `/` | GET | Проверка работы API |
| `/health` | GET | Статус сервера |
| `/quote/{ticker}` | GET | Получить данные по акции (пример: /quote/SBER) |
| `/history` | GET | История запросов из БД |
