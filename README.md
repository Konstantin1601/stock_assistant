# Stock Assistant - Ассистент по акциям РФ

Веб-приложение для получения информации об акциях с Московской биржи (MOEX).

## Возможности

- Получение текущей цены акции
- График изменения цены за сегодняшний день
- Умный поиск тикеров с фильтрацией по вводу
- Отображение максимума, минимума и изменения цены в процентах
- История всех запросов с фильтром
- Очистка истории запросов
- Автоматическое сохранение истории в базу данных SQLite

## API Эндпоинты

| Эндпоинт | Метод | Описание |
|----------|-------|----------|
| '/' | GET | Проверка работы API |
| '/health' | GET | Статус сервера |
| '/quote/{ticker}' | GET | Получить данные по акции |
| '/candles/{ticker}' | GET | Получить историю цен для графика |
| '/tickers' | GET | Получить список всех доступных тикеров |
| '/history' | GET | История запросов из БД |
| '/history/clear' | DELETE | Очистить историю запросов |
